Keyboard shortcuts

Move

← →
Previous / next beat
↑ ↓
Previous / next string
Ctrl+← →
Previous / next measure
Home / End
First / last beat of the measure
Ctrl+Home / End
Start / end of the score
PageUp / PageDown
Previous / next track

Selection

Shift+← →
Extend by one beat
Ctrl+Shift+← →
Extend to the barline
Shift+Home / End
Extend to the measure start or end
Ctrl+Shift+Home / End
Extend to the start or end of the score
Shift+↑ ↓ or Shift+PageUp / PageDown
Extend to the previous / next track (whole measures)
Ctrl+A
Select the whole track; press again for all tracks

Enter

0–9
Fret on the cursor string (two quick digits: 10–24)
R
Rest / note (with a selection: every selected beat)
L
Tie to the previous note on this string (with a selection: tie or untie every pair of equal notes)

Rhythm

+ or =
Shorter duration
-
Longer duration
.
Dots 0 → 1 → 2
/
Triplet on / off

With a selection: every selected beat.

Edit

Delete / Backspace
Delete the note on the string, or turn a selection into rests
Ctrl+Delete / Ctrl+Backspace
Delete the beat, or the selected beats
Insert or I
Insert a rest before the beat
Esc
Clear the selection or a two-digit fret

Clipboard

Ctrl+C
Copy
Ctrl+X
Cut (the beats become rests)
Ctrl+V
Paste: measures go over the selected or blank measures (else before the cursor); beats go before the cursor, replacing a selection; measures onto a beats selection are refused
Ctrl+Shift+V
Paste as new measures or beats, replacing nothing

Click the score first.

Measures

M / Shift+M
Insert a measure after / before
Shift+Delete / Shift+Backspace
Delete the measure, or the selected measures
F
Fill with rests
Shift+F
Move overflow to the next measure, and on through the following measures

Pickup: use Measure… at measure 1.

Transpose

Ctrl+↑ ↓
Up / down 1 semitone (the note, or the selection); a note past fret 0 or the top fret moves to the nearest string
Ctrl+Shift+↑ ↓
Up / down an octave

Effects

H
Hammer-on/pull-off on / off
S
Slide → legato slide → off
Shift+S
Slide in from below / above → slide out down / up → off
B
Bend full → half → full and release → pre-bend full → release → off
Shift+B
Bend, the same values backwards
V
Vibrato → wide vibrato → off
P
Palm mute on / off (rests too)
X
Dead note on / off; on an empty string adds a dead note
G
Ghost note on / off
N
Natural → pinch harmonic → off
Shift+L
Let ring on / off
D
Dynamic louder (from nothing: mf; rests too)
Shift+D
Dynamic softer (from nothing: mp; rests too)
A
Accent → marcato → off
Shift+A
Staccato → staccatissimo → off

With a selection, each key acts on every selected beat or note.
