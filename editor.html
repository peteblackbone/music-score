Click the score or press Tab to start editing. Keyboard shortcuts are listed below.

Track: – Measure: – Beat: – String: – Fret: – Duration: – Fill: – Effects: – Read-only

Keyboard shortcuts

Move

← →
Previous / next beat
↑ ↓
Previous / next string
Ctrl+← →
Previous / next measure
Home / End
First / last beat of the measure
Ctrl+Home / End
Start / end of the score
PageUp / PageDown
Previous / next track

Enter

0–9
Fret on the cursor string (two quick digits: 10–24)
R
Rest / note
L
Tie to the previous note on this string

Rhythm

+ or =
Shorter duration
-
Longer duration
.
Dots 0 → 1 → 2
/
Triplet on / off

Edit

Delete / Backspace
Delete the note on the string
Ctrl+Delete / Ctrl+Backspace
Delete the beat
Insert or I
Insert a rest before the beat
Esc
Cancel a two-digit fret

Measures

M / Shift+M
Insert a measure after / before
Shift+Delete / Shift+Backspace
Delete the measure

Effects

H
Hammer-on/pull-off on / off
S
Slide → legato slide → off
Shift+S
Slide in from below / above → slide out down / up → off
B
Bend full → half → full and release → pre-bend full → release → off
Shift+B
Bend, the same values backwards
V
Vibrato → wide vibrato → off
P
Palm mute on / off (rests too)
X
Dead note on / off; on an empty string adds a dead note
G
Ghost note on / off
N
Natural → pinch harmonic → off
Shift+L
Let ring on / off
D
Dynamic louder (from nothing: mf; rests too)
Shift+D
Dynamic softer (from nothing: mp; rests too)
A
Accent → marcato → off
Shift+A
Staccato → staccatissimo → off

History

Ctrl+Z
Undo
Ctrl+Y / Ctrl+Shift+Z
Redo

On Mac, Cmd works in place of Ctrl. Tab leaves the editor.
