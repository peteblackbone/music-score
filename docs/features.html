music-score features

A small vanilla JavaScript library that draws music notation and guitar tablature as SVG, from a plain JSON score, using the Bravura (SMuFL) music font. No build step, no dependencies.

Every example on this page is rendered live by the library. Expand "Score JSON" under an example to see its input. Full field reference: README.md.

This page loads ES modules and a font file, so it must be served over http. From the project folder run python -m http.server 8765 --bind 127.0.0.1 and open http://127.0.0.1:8765/docs/features.html.

Quick start

import { MusicScoreRenderer, defaultTheme } from './index.js';

const renderer = new MusicScoreRenderer(document.getElementById('score'), score, { width: 860 });
renderer.render();          // draws (and redraws) the whole SVG; returns the renderer
renderer.setScore(other);   // swap the score, then call render() again

Notation and tablature

A track can show a notation staff, a tab staff, or both. Notes given by string and fret get their pitch from the track's tuning and are written an octave above sounding pitch, as guitar music is, under an 8vb clef. Six- and four-string tabs use the SMuFL TAB clef. A tab-only track shows its rhythm below the tab staff (stems, beams, flags, dots, tuplets, with rests inside the staff); set tabRhythm: false to hide it, or tabRhythm: true to add it to a tab staff under notation.

Multi-instrument systems

Tracks stack into systems. Beats that start at the same time line up on every staff. Staves are joined by a line; a notation + tab pair is bracketed when the system holds two or more instruments. The full name is drawn on the first system and the short label after that. Bass parts can use writtenOctaveUp to be written an octave above sounding pitch.

Page header

title is centred, composer is right-aligned, tuningLabel sits at the left under the title, and tempoText sits above the first system at the time signature. Subtitle, artist, album, words, music, instructions and copyright are also available; see Score text.

Line breaks and justification

  • Measures are spaced by duration and broken into systems to fit the width. Every system except a short last one is stretched to full width.
  • The time signature appears only at the start and where it changes; clef and key repeat on each system.
  • A key or time change at a line break gets a courtesy signature at the end of the previous system.
  • Measure numbers mark the start of systems 2 onward.
  • Vertical gaps follow the content, so tall passages get more room.

Barlines and repeats

Barline types: single, double, final, repeatStart, repeatEnd. Barlines are drawn per staff, so they never run through the gap between notation and tab. A barline just before a repeat start merges into the repeat sign, and an end repeat followed by a start repeat becomes one combined sign.

Endings and navigation

Measure fields for volta brackets and navigation marks. They apply to the whole measure column, so you can set them on any track; on a conflict the lowest track wins. They are drawn above the top staff of each system and do not change the horizontal spacing.

FieldDrawn as
endingVolta bracket labelled "1." or "1., 2.": 1, [1, 2], or { numbers, text, open } (text replaces the label, open overrides the closing hook)
segno: trueSegno sign at the start of the measure
coda: trueCoda sign at the start of the measure
jumpBold italic text ending at the closing barline: D.C., D.C. al Fine, D.C. al Coda, D.S., D.S. al Fine, D.S. al Coda, To Coda (with a small coda sign), Fine; other text is drawn as written
  • Consecutive measures with the same ending share one bracket. A different ending, a measure without one, or a repeat start begins a new one.
  • A bracket gets a closing hook when its last measure ends with an end repeat; otherwise it stays open.
  • A bracket that crosses a line break continues on the next system without a number.
  • Brackets sit above chord symbols, chord diagrams and fermatas, and the signs and jump texts sit above the brackets. Section markers sit in a row above those, and the tempo stays on top.
  • Nothing is played or unrolled: the marks are drawn as written.

Score text, sections and repeat counts

Text fields for the header, plus marks players read: section markers, x3 repeat counts, and free text on a beat.

FieldDrawn as
subtitle, artist, albumCentred header lines under the title, each in a smaller text
words, music"Words by" at the left and "Music by" at the right; one "Words & Music by" line when they are the same name
instructions, copyrightItalic lines under the credits, and centred lines at the foot of the score. Split at line breaks, up to 8 lines each
capo (track)"Capo fret N" in the header for that track. Display only: the music is not transposed
showTuningChart: true (score)Lists the strings tuned differently from the usual tuning, such as "⑥ = D", in the header
section (measure)'Verse' or { letter, text }: a boxed letter with the text after it, or boxed text, above the staff
repeatCount (measure)x3 at the end of a measure with an end repeat; 2 to 99
text (beat)Italic text above the staff, or below it with { text, below: true }. Note and rest beats in voice 1
  • A score that uses none of these fields looks as it did before.
  • Lines do not wrap. Beat text takes no horizontal room, and a section marker only moves right to keep a gap from the previous one on its system.
  • A section sits at the start of its measure, or where a segno would go. A repeat count needs an end repeat in its measure.
  • The capo is only written, not applied: the music is not transposed. A chart lists nothing for standard tuning.

Rhythm and beaming

Durations from whole to 64th, dots, rests and tuplets. Eighths and shorter beam within each beat; compound meters such as 6/8 and 12/8 beam by dotted beat. An empty measure draws a centred whole-measure rest.

Pitch, keys and accidentals

Key signatures from 7 flats to 7 sharps, changeable mid-score. Accidentals follow standard rules: they last to the end of the measure, a cancelling natural is added when needed, and stacked accidentals in chords are spread into columns. Notes a second apart in a chord sit on either side of the stem.

Ties and slurs

Ties connect notes of the same pitch (enharmonic spellings count), slurs span phrases. Both sit opposite the stems, and both are split into two arcs when they cross a line break.

Articulations, fermatas, dynamics, chord symbols

Staccatissimo, staccato, tenuto, marcato and accent go on the side opposite the stem and stack in a fixed order. Fermatas come in normal, short and long forms and sit above everything on the beat. Chord symbols share one line above each system and dynamics one line below, both kept clear of the notes.

  • marcato (or heavyAccent) and staccatissimo are drawn as their own marks. When both halves of a pair are given, the stronger one replaces the other: staccatissimo replaces staccato, and marcato replaces accent.
  • A taller mark that would touch its notehead moves out one staff space.
  • fermata: 'short' and 'long' are the short and long fermatas. 'normal' and true give the usual one.
  • vibrato: 'wide' draws a taller, heavier wave than true, on notation and TAB. tremolo: '8th' and '16th' draw one and two strokes; '32nd' and true draw three.

Chord diagrams

Fretboard boxes above the chord symbols, as in lead sheets and guitar books. List the shapes once in the score's chordShapes, keyed by chord name; every beat whose chord matches gets a diagram with the name centred above it.

FieldMeaning
fretsOne entry per string, low to high like tuning: a fret from 0 to 24, or 'x' / null for a muted string
fingersOptional, low to high: 1 to 4 or 'T', drawn under the grid
barreOptional { fret, from, to }. Strings are numbered like notes (1 = highest); the default runs from the lowest string to string 1
baseFretOptional first fret of the grid. By default the grid starts at the nut, or at the lowest fret with "5fr" beside it when a fret is above 4
  • Tracks with TAB show diagrams by default. A notation-only lead sheet opts in with showChordDiagrams: true; false turns them off for a track.
  • A beat's chordDiagram replaces the dictionary shape for that beat, and chordDiagram: false keeps a plain chord symbol.
  • An invalid shape (wrong number of strings, a bad fret, more than 5 frets apart) falls back to the plain chord symbol.
  • The diagrams of a system's staff sit in one row above the music, and their names share one line with the plain chord symbols. Fermatas, endings, signs and the tempo sit above them.
  • On a tab-only track the diagrams go above the TAB, outside pick strokes, labels and bends. Diagrams take no horizontal space, so close chord changes can overlap.

Guitar techniques

FieldDrawn as
hammerPullSlur with H or P to the next note on the string, on tab and on notation (hammerPullSlurs: false in the theme turns the notation slurs off)
slideDiagonal stroke to the next note. 'legato' adds a letterless arc on TAB and a slur on notation
slideInShort slide into the note: true, 'up' or 'below' from below; 'down' or 'above' from above
slideOutShort slide off the note: true or 'down' downward; 'up' upward
bendArrow with amount (1/2, full, 1 1/2…), optional release or hold; 'prebend full' (or 'pb 1/2') bends before the pick; 'release' is a note that falls back to the unbent pitch
bend, compound'1/2 release full' (or 'pb 1/2 release full', or { type: 'bend', amount, rebend }): rise, fall back, and rise again, with both amounts labelled
palmMute"P.M." with a dashed line over consecutive beats
vibratoWavy line on notation and TAB; 'wide' draws a taller, heavier wave
tremoloTremolo slashes: three for true; '8th', '16th' or '32nd' draw one, two or three
mute, ghostx notehead / x on tab; parentheses
type: 'grace'Small slashed note slurred to the next beat
harmonic, harmonicFretNatural: diamond and <12> on tab. Artificial, tapped, pinch, semi: A.H., T.H., P.H., S.H. label; harmonicFret gives the touched fret, e.g. 5(17). Feedback ('feedback'): normal notehead, plain fret and an Fdbk. label
letRingDashed "let ring" label over consecutive beats, like P.M.; a rest inside the run keeps it going
pickStroke'down' or 'up': ⊓ or ∨ above the beat
strum'down' or 'up': a strum arrow ↓ or ↑ above the TAB (above the notation staff on a track without TAB); replaces the pick stroke
arpeggiotrue, 'up' or 'down': a wavy line left of a chord on notation and TAB, with an arrowhead at the top or bottom
tap (on a note)"T" above the note on notation, or above the fret on TAB
slap, pop (on a note)"S" or "P" in the tap "T" place, on notation and TAB (tap wins over slap, slap over pop)
whammyWhammy-bar mark on TAB: true, a string or { type: 'dip' } is a V with -1/2 above it (true means 1/2); { type: 'dive', amount } slopes down and is held until a { type: 'return' } beat rises again, across line breaks; { type: 'predive', amount } is a level lead-in before the note, then the rise
rakeDashed "rake" label over the beat and the dead-note grace notes just before it
trill (on a note)"tr" with a wavy line on notation and TAB; 7 or 'B3' adds (7) on TAB. A note tied to it with tieEnd continues the wave, across line breaks too
whammyScoop (beat)Small V into the note on TAB, with no text; a pre-dive on the same beat wins
whammyBar (beat)"w/bar" label run on TAB, like let ring; set it on note beats
tiedFrets: 'parens' (track)Parentheses around the fret of a tied-to note on TAB, such as (5). Off by default; see the example after this table
tabRhythm (track)Stems, beams, flags, dots, tuplets and rests under the TAB staff. On by default for tab-only tracks; false hides it, true adds it to a track that also shows notation. See Rhythm on tab
  • A run of hammer-ons and pull-offs on one string shares one slur on notation, as well as the H and P arcs on tab. Notes need string.
  • slideIn and slideOut draw a short slide on tab and notation. They take no horizontal room. A slide-in is left out when a slide or hammer-on already leads into the note, and a slide-out when the note has its own slide to another note or a bend.
  • A pre-bend is bent before the note is picked. On tab it is a rising shaft with the amount and no landing fret. Add release to bend back down.
  • A release note ('release') falls back to the unbent pitch, with its fret in parentheses. Its amount is the last bend on that string, or a full step.
  • Pre-bends, releases and compound bends are drawn on tab only.
  • A compound bend ('1/2 release full') rises, falls back to the string's level and rises again, with both amounts labelled. A release note after it falls by the second amount.
  • slide: 'legato' is a slide with a slur: a letterless arc on TAB and a slur on notation, even with hammerPullSlurs: false.

With tiedFrets: 'parens' on the track, each tied-to note shows its fret in parentheses on TAB. The note that starts the tie is unchanged.

Harmonics

Set harmonic on a note. Natural harmonics (true or 'natural') get a diamond notehead and a <12> fret on tab, with no label. Artificial, tapped, pinch and semi harmonics keep a normal notehead and get an A.H., T.H., P.H. or S.H. label above the tab. harmonicFret adds the touched fret, as in 5(17).

  • Consecutive beats with the same label share one dashed line, as palm mute does. P.M. sits nearest the staff, and a harmonic label sits outside it.
  • Labels move clear of bends. A muted note is drawn as an x, with no harmonic.
  • Grace notes get a diamond or TAB text, but no harmonic label.

Picking and playing directions

Beat fields for the marks players read: letRing for a let-ring run, pickStroke for down and up picks, strum and arpeggio for strummed and spread chords, tap, slap, pop and trill on a note, and whammy and rake on a beat. None of them change the rhythm; only arpeggio adds room left of its chord.

  • Consecutive letRing beats share one dashed "let ring" label, and an unmarked rest between them keeps the run going. The label sits outside any P.M. or harmonic label.
  • Pick strokes sit above the notation staff, one per beat, and beats in one beam group share a height. In a two-voice measure, voice 2's sit below the staff. On a tab-only track they sit above the TAB.
  • A tapped note gets a "T" above its note or fret. A tapped harmonic shows only its T.H. label.
  • A whammy dip is drawn on the TAB staff only, as a V with its amount above it. true means 1/2.
  • A whammy dive slopes down (0.8 to 2.4 sp deep, by amount) and stays held, as a level line, until a beat with { type: 'return' }, where it rises again. A dip, another dive or a pre-dive ends the hold early with no rise. A hold carries over a line break, stopping 0.5 sp before the barline and resuming after the next header without text. A pre-dive is a short level lead-in before its note, then the rise. The line is lifted above any frets, marks, letters, trills and bends under it.
  • A slapped or popped bass note gets an "S" or "P" above it, in the same place as the "T". One letter per beat: tap, then slap, then pop.
  • A rake is a dashed "rake" label over its beat and the grace notes right before it. Write those dead-note grace notes yourself. The label sits outside any P.M. or let-ring label it overlaps.
  • A trill is "tr" and a wavy line above the beat, on notation and TAB, above any vibrato or tremolo and below a "T", pick stroke or fermata. On TAB, a fret or pitch target adds (7). Consecutive trills on a system share one height. The wave stops before the next beat (or the next "tr") and at a line break.
  • A strum arrow ('down' ↓, 'up' ↑) sits above the TAB staff, clear of the frets and marks under it, or above the notation staff on a track without TAB. Consecutive strums on a system share one height, so a rasgueado run reads as one line. A strum replaces the beat's pick stroke.
  • An arpeggio is a wavy line just left of a chord, on notation and TAB, spanning its notes. 'up' adds an arrowhead at the top, 'down' at the bottom. The chord keeps room for the line, 1 sp beyond its leftmost ink, and grace notes stay left of the line.
  • Rests and grace notes ignore pick strokes, strums, arpeggios, taps, slaps, pops, trills, whammy marks and rakes. A single note ignores an arpeggio.

1.9.0 additions: compound bends, a legato slide, a whammy scoop and a "w/bar" run on the TAB, a feedback harmonic, and a trill that runs over the note tied to it, onto the next system if needed.

Ornaments and hand marks

Note fields for ornaments and fingering, and beat fields for the hand marks: ornament, finger and rightFinger on a note, leftHandTap on a note, golpe, pickScrape and barre on a beat. Scores that use none of them draw as before.

FieldDrawn as
ornament (note)'turn', 'invertedTurn', 'upperMordent' or 'lowerMordent' above the beat, on notation. Aliases: 'turnInverted', 'invertedMordent', 'shortTrill', 'mordent'. Case and spaces are ignored
finger (note)Left-hand fingering, left of the chord on notation: 1 to 4, 'T', or 0 (drawn as a plain 0, the open-string sign)
rightFinger (note)Italic 'p', 'i', 'm', 'a' or 'c' above the beat, stacked for a chord. Above the TAB on a tab-only track
leftHandTap (note)Left-hand tapping sign in the tap "T" place, on notation and TAB
golpe (beat)Golpe sign above the tap "T" place, on notation and TAB: true, 'thumb' or 'finger'
pickScrape (beat)Dashed "P.S." label over consecutive beats, like let ring: true, 'down' or 'up' (the direction is not drawn)
barre (beat)Label "C II" for 2, or "½C V" for { fret: 5, half: true }. Repeated after a system break
  • An ornament sits in the trill's place, one per beat. A trill on the same beat wins.
  • Left-hand fingering takes room left of its chord, and only where a note has a finger. A second digit for a note a staff position from another moves a column further left.
  • A beat shows one tap mark: tap "T", then left-hand tap, then slap "S", then pop "P". A tapped harmonic ignores leftHandTap.
  • The golpe sits above the tap letter's place, clear of a trill or hammer-on letter on TAB. A rest has none.
  • Labels stack from the staff in this order: P.M., harmonic, let ring, P.S., barre, rake.
  • Rests and grace notes draw none of these marks. A rest may sit inside a P.S. or barre run, and a grace note inside a barre run.
  • On voice 2, ornaments, trills, right-hand letters, tap letters, golpe and pick strokes are drawn below the notation staff. Left-hand fingering and the other marks are voice 1 only. Ornaments and left-hand fingering are not drawn on TAB.

Rhythm on tab

A tab-only track (showStandardNotation: false, showTablature: true) shows its rhythm under the TAB staff by default, as in tab books: stems, beams, flags, augmentation dots, tuplets and rests. Set tabRhythm: false to keep plain fret numbers. A track that also shows notation gets this only with tabRhythm: true.

  • Stems hang below the strings, one per note or chord. Half notes get a short stem, and whole notes none.
  • Eighths and shorter beam as in notation. Unbeamed eighths to 64ths get smaller flags.
  • A tuplet shows its number under a single beam, or a bracket otherwise.
  • Rests sit inside the staff. An empty measure (beats: []) shows a whole-measure rest.
  • The band adds height below the TAB staff. Marks above the staff keep their place.
  • In a two-voice measure, voice 2 gets a second row below voice 1's, and an unmerged rest sits in its voice's row.

Two voices on one staff

A measure can hold two rhythms at once, as in a melody over a held bass. Give the measure voices instead of beats: the first entry is voice 1 (stems up) and the second is voice 2 (stems down). Both show on notation and on TAB.

  • Ties and slurs stay within their voice: voice 1 above the notes, voice 2 below. Articulations sit on the stem side.
  • A unison where both voices play the same note at the same time shares one notehead. Other clashes move voice 2 right, and accidentals are shared between them.
  • A rest that both voices take at the same time, for the same length, is drawn once.
  • Voice 2 can carry vibrato, trills, ornaments, right-hand letters, tap letters, golpe, pick strokes and fermatas. On notation they sit below the staff, and a voice 2 fermata is inverted.
  • On TAB each voice has a rhythm row, voice 2's below voice 1's. An unmerged rest sits in its row, so it never covers the other voice's frets.
  • A { type: 'rest', hidden: true } takes time without drawing anything, which lets a voice start later.
  • Chord symbols, dynamics, left-hand fingering, strums, arpeggios and the other playing marks are read from voice 1 only.

A TAB-only track shows each voice's rhythm: voice 1 on the first row under the TAB, voice 2 on a second row below it. A rest that both voices take at the same time is drawn once, in the staff.

Theming

Pass options.theme to override any key of defaultTheme: colours (noteColor, staffLineColor, tabFretColor, background), fonts, line widths and spacing. Spacing keys ending in Sp are in staff spaces, so staffLineSpacing scales the whole score. Rhythm on tab uses tabStemGapSp, tabStemLengthSp, tabHalfStemLengthSp, tabFlagScale and tabFretColor.

Not included

  • Playback, an editor, and import/export of other formats (design notes for these are in ARCHITECTURE.md).
  • Different time signatures across tracks in the same measure.
  • Glyph and text widths are estimated, not measured from the font.
